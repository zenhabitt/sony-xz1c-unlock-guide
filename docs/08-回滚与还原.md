# 08 · 回滚与还原

> 这个机型几乎不会真变砖：bootloader 在、flash mode 在，就有的救。

| 难度 | 耗时 | 风险 | 前置 |
|---|---|---|---|
| ★★☆ | 视情况 10–60 分钟 | 中（回滚本身安全，但操作要准） | 能进 Fastboot 或 Flash mode |

---

## 8.1 判断损坏程度

| 现象 | 坏在哪 | 能救 |
|---|---|---|
| 卡 logo / 开机循环 | boot 或 data | ✅ 重刷 boot 或固件 |
| 进不了系统但能进 Fastboot（蓝灯） | boot / system | ✅ `fastboot flash` |
| 进不了系统但能进 Flash mode（绿灯） | 几乎全部 | ✅ newflasher 全刷 |
| 连 Flash mode 都进不去 | bootloader 区 | ⚠️ 需 EDL |
| 设备管理器显示 `QUSB_BULK` / `9008` | EDL 模式 | ⚠️ 需签名 firehose |

正常操作最多到第三行。

---

## 8.2 最小回滚：只恢复 boot

```bash
$FB flash boot "$KIT/backup/boot-current.img"
$FB reboot
```

（没有备份就从固件里解一个原厂 boot。）

---

## 8.3 恢复被改过的分区

| 分区 | 备份文件 | 参考大小 |
|---|---|---|
| `abl` | `abl-current.img` | 1,572,864 |
| `boot` | `boot-current.img` | ~19,615,744 |
| `xfl` | `xfl-current.img` | 31,457,280 |

**方式一：fastboot**

```bash
$FB flash abl "$KIT/backup/abl-current.img"
```

> `xfl` 是 bootloader 组件，**不建议直接 fastboot flash**，写错会进不了 fastboot。
> 要恢复 XFL 优先用 §8.4 的整体重刷。

**方式二：临时 root 后 dd**

```sh
dd if=/sdcard/abl-current.img of=/dev/block/bootdevice/by-name/abl
```

---

## 8.4 完整回滚到原厂 8.0

最稳的恢复方式，也是"解锁后开机循环"的标准解法。

1. 关机 → 音量下 → 插 USB（绿灯）
2. ```bash
   cd "$KIT/firmware/docomo-8.0"
   "$KIT/tools/newflasher.x64"
   ```
3. 四个提示全答 `n`
4. 等到 `Device is put now out of flash mode.`
5. 拔线开机

> 重刷原厂**不会**重新上锁，`unlocked` 状态保留。

---

## 8.5 关于重新上锁（不要做）

```bash
fastboot oem lock      # 不要随便执行
```

风险：

- boot 分区只要不是**完全未修改的原厂镜像**，上锁后设备拒绝启动 → 变砖
- 索尼会校验所有分区签名
- 变砖后需要 EDL + 签名 firehose，普通手段救不回来

**结论：解锁了就一直保持解锁，上锁没有任何收益。**

---

## 8.6 备份清单

刷机前应确认手上有：

| 项目 | 是否必需 | 说明 |
|---|---|---|
| 原厂固件 | ✅ | 救砖根本 |
| 原始 `xfl` 分区 | 建议 | 恢复 bootloader 组件 |
| 原始 `abl` 分区 | 建议 | — |
| 原厂 `boot` | ✅ | boot 打坏时回滚 |
| 当前 ROM | 建议 | 重刷系统 |
| TA / DRM | ❌ 不需要 | xperable 不擦 TA |

> xperable 的最大好处：**不碰 TA**。DRM 密钥、相机调校参数都还在，
> 不需要像官方解锁那样提前备份 TA。
