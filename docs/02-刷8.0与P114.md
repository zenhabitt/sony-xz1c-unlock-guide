# 02 · 刷 Android 8.0 与 P114 Bootloader

**中文** | [English](en/02-flash-8.0-and-p114.md)

> **为什么必须 8.0**：xperable 依赖的 ABL / LinuxLoader 布局只在 8.0 的固件组合下成立。
> **为什么必须 P114**：只有 P114 这个 bootloader 的 `LinuxLoader-p114.pe` 能被 patch。

| 难度 | 耗时 | 风险 | 前置 |
|---|---|---|---|
| ★★☆ | 20–40 分钟 | 中（固件刷写，会清数据） | [01](01-准备.md) |

---

## 2.1 刷入 Android 8.0（47.1.F.1.105）

固件来源见 [DOWNLOADS.md](../DOWNLOADS.md) §B1，放到 `$KIT/firmware/docomo-8.0/`。

目录结构必须是 newflasher 认识的样子：

```
docomo-8.0/
├─ boot/                 bootloader_*.sin + Lilac_Docomo_XBootConfig_MiscTA.ta
├─ partition/            partition-image-LUN*.sin
├─ system.sin  userdata.sin  vendor.sin  kernel.sin ...
├─ boot_delivery.xml
└─ partition_delivery.xml
```

### 操作

1. 手机关机 → 按住 **音量下** → 插 USB → **绿灯**
2. 命令行进入固件目录运行 newflasher：

```bash
cd "$KIT/firmware/docomo-8.0"
"$KIT/tools/newflasher.x64"
```

### 四个提示，全部答 `n`

| # | 提示 | 回答 | 原因 |
|---|---|---|---|
| 1 | need GordonGate flash driver? | `n` | 驱动单独装 |
| 2 | dump trim area (TA)? | `n` | **答 y 会触发 buffer overflow 崩溃** |
| 3 | flash bootloader/bluetooth/dsp/modem to both slots? | `n` | 单卡机，双槽有风险 |
| 4 | flash persist partition? | `n` | **persist 绝对不能刷**，会丢 attestation key |

### 成功标志

```
Device is put now out of flash mode.
Sent command: Sync

End. You can disconnect your device when you close newflasher.exe
```

拔线，按电源开机。首次启动可能几分钟。

## 2.2 刷 P114 Bootloader

8.0 固件自带 **O_82**（LA1.1）bootloader，我们需要 **P114**（LA2.0）。

背包里有三个 ABL 变体：`5ADA` / `5D31` / `C93B`。

**选择依据**：刷入时 newflasher 会验证 boot delivery 并打印匹配项，例如

```
Found bootdelivery match: COMMERCIAL_0005E0E1
```

本机（SO-02K）实测匹配 **C93B**。

> 三个变体的 ABL 二进制除末尾 256 字节 RSA 签名外基本相同，
> 但**签名必须匹配**，不匹配会被 bootloader 拒绝。

### 组装 newflasher 目录

```bash
mkdir -p "$KIT/firmware/p114/boot"
cp "$KIT/firmware/p114/C93B/bootloader_X_Boot_MSM8998_LA2_0_P_114_X-FLASH-ALL-C93B.sin" \
   "$KIT/firmware/p114/boot/"
cp "$KIT/firmware/docomo-8.0/boot/Lilac_Docomo_XBootConfig_MiscTA.ta" \
   "$KIT/firmware/p114/boot/"
```

### 刷入

1. 关机 → 音量下 → 插 USB（绿灯）
2. 在 `$KIT/firmware/p114` 目录运行 newflasher
3. 提示依旧 `n` / `n` / `n`

成功输出类似：

```
Found boot_delivery.xml in boot folder.
- Boot delivery version: 1306-5035
- Verifying if boot delivery match with device...
Found bootdelivery match: COMMERCIAL_0005E0E1
TA file: Lilac_Docomo_XBootConfig_MiscTA.ta
Processing bootloader_X_Boot_MSM8998_LA2_0_P_114_X-FLASH-ALL-C93B.sin
...
flash:bootloader
OKAY.
```

### 验证

进 Fastboot（音量上 + 插线）：

```bash
$KIT/tools/platform-tools/fastboot getvar version-bootloader
```

必须包含：

```
1306-5035_X_Boot_MSM8998_LA2.0_P_114
```

**没有 `P_114` 就不要往下走。**

## 2.3 开机并开启 USB 调试

1. 正常开机，完成初始设置（Google 账号可跳过）
2. 设置 → 关于手机 → 连点「版本号」7 次
3. 开发者选项 → 打开 **USB 调试**
4. 插线，手机上允许授权

```bash
$ADB devices     # 应为 device
```

---

## 2.4 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `*** buffer overflow detected ***` | TA dump 答了 y | 重跑，答 n |
| `getvar:max-download-size` 超时 | flash 会话卡死 | 拔线重插，重进 flash mode |
| bootloader 被拒 | ABL 变体签名不匹配 | 换 5ADA / 5D31 / C93B |
| 刷完卡 Sony logo | 分区不完整 | 重刷一次 8.0 |
