## 1.2 装驱动（Windows）

### A. ADB 驱动

插线、开启「USB 调试」后通常自动装好：

```powershell
$KIT\tools\platform-tools\adb devices
# List of devices attached
# XXXXXXXXXXXX    device
```

显示 `unauthorized` → 手机屏幕点「允许 USB 调试」。

### B. Fastboot 驱动（关键）

Windows 自带驱动经常不认索尼，用 Zadig：

1. 手机**关机** → 按住 **音量上** → 插 USB（等蓝灯）
2. 设备管理器里应出现带黄色感叹号的未知设备
3. 右键 `zadig.exe` → **以管理员身份运行**
4. `Options` → `List All Devices`
5. 下拉框选索尼设备（VID `0FCE`）
6. 驱动选 **WinUSB** → `Install Driver` / `Replace Driver`

验证：

```powershell
$KIT\tools\platform-tools\fastboot devices
# XXXXXXXXXXXX    fastboot
```

### C. Flash mode 驱动

newflasher 需要把设备识别成 `SOMC Flash Device`。
若识别不到，按 newflasher 的提示安装 GordonGate 驱动，或装 Flashtool 的 Flashmode 驱动。

## 1.3 三种状态

| 状态 | 操作 | LED | 电脑看到 | 用途 |
|---|---|---|---|---|
| **Fastboot** | 关机 → 按住 **音量上** → 插 USB | 蓝 | `<serial> fastboot` | xperable、刷 boot/recovery |
| **Flash mode** | 关机 → 按住 **音量下** → 插 USB | 绿 | `SOMC Flash Device` | newflasher 刷固件 |
| 正常开机 | 按电源 | — | `<serial> device` | adb shell |

> 「关机」= 电源键菜单选关机，等完全断电。

## 1.4 确认机型

```bash
$ADB shell getprop ro.product.model     # SO-02K
$ADB shell getprop ro.product.device    # lilac
$ADB shell getprop ro.build.version.release   # 8.0.0
$ADB shell getprop ro.build.id                # 47.1.F.1.105
```

**本流程要求 Android 8.0（47.1.F.1.105）**，不符先做 [02](02-刷8.0与P114.md)。

## 1.5 备份（在 03 拿到临时 root 后立刻做）

| 分区 | 命令 | 大小参考 |
|---|---|---|
| `xfl` | `dd if=/dev/block/bootdevice/by-name/xfl of=/sdcard/xfl-current.img` | 31,457,280 |
| `abl` | `dd if=/dev/block/bootdevice/by-name/abl of=/sdcard/abl-current.img` | 1,572,864 |
| `boot` | `dd if=/dev/block/bootdevice/by-name/boot of=/sdcard/boot-current.img` | ~19,615,744 |

取回电脑：

```bash
$ADB pull /sdcard/xfl-current.img $KIT/backup/
$ADB pull /sdcard/abl-current.img $KIT/backup/
$ADB pull /sdcard/boot-current.img $KIT/backup/
```

辅助脚本：
- `scripts/partinfo.sh` — 列分区与大小
- `scripts/dump_bl.sh` — 批量 dump bootloader 相关分区

> **换一台设备必须重新 dump**，不要用别人的备份。

## 1.6 驱动问题速查

| 现象 | 处理 |
|---|---|
| `fastboot devices` 空 | 用 Zadig 重装 WinUSB |
| `adb devices` 显示 `offline` | 换数据线，重新授权 |
| 设备反复断开重连 | 换 USB 2.0 口 |
| newflasher 找不到设备 | 装 Flash mode 驱动 |
